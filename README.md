## 📖 Overview

**CSS City Skyline** is a creative front-end development project that recreates a colorful urban skyline using only HTML5 and CSS3.

The illustration features multiple architectural structures arranged into background and foreground layers, creating a cityscape with different building heights, geometric rooftops, colorful windows, and gradient-based architectural details.

The project explores how CSS can be used beyond traditional website styling to create detailed visual illustrations without relying on JavaScript, external frameworks, or image assets.

The implementation focuses on CSS gradients, custom properties, Flexbox, positioning, element dimensions, and responsive styling.

## ✨ Key Features

- **Pure CSS Illustration:** Creates an entire city skyline using HTML elements and CSS styling.
- **Layered Building Structures:** Separates background and foreground buildings to create visual depth.
- **CSS Custom Properties:** Uses reusable color variables for building and window styles.
- **Repeating Linear Gradients:** Produces architectural patterns and decorative window arrangements.
- **Radial Gradient Background:** Creates a stylized sky with a sun-inspired gradient effect.
- **Flexbox Layout:** Organizes buildings and their internal components using flexible layouts.
- **Geometric Architecture:** Uses CSS borders and transparent borders to construct triangular rooftops.
- **Custom Window Designs:** Creates different window patterns using gradients, dimensions, and border-radius.
- **Responsive Styling:** Changes the skyline's color theme at smaller viewport widths.
- **Lightweight Implementation:** Requires no JavaScript, external libraries, or CSS frameworks.

### CSS Implementation Highlights

**1. CSS Custom Properties**

Reusable variables define the building and window colors, making it easier to maintain and update the overall visual theme.

**2. Repeating Linear Gradients**

The `repeating-linear-gradient()` function creates repeated architectural patterns, including building facades and window arrangements.

**3. Radial Gradients**

The `radial-gradient()` function creates a stylized sky background with a central color transition.

**4. Flexbox Layout**

Flexbox positions buildings along the skyline and organizes windows within individual building structures.

**5. CSS Border Techniques**

Transparent borders and solid borders are combined to create geometric rooftop shapes without using images.

**6. Responsive Styling**

CSS media queries modify the custom properties and sky background when the viewport width reaches the defined breakpoint.

## 📱 Responsive Design

The project includes a responsive color-theme adjustment using CSS media queries.

**Larger Screens:**
- Displays the original colorful architectural palette.
- Uses layered background and foreground structures.
- Maintains the skyline's original building arrangement.

**Screens Below 1000px:**
- Changes building colors to black.
- Changes window colors to gray.
- Applies a darker sky gradient.
- Preserves the overall architectural composition.
